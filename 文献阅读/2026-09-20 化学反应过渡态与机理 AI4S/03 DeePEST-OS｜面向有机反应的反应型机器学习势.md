# DeePEST-OS：用半经验基线与等变势加速有机反应过渡态搜索

[[00 总索引｜化学反应过渡态与机理 AI4S]]

## 1 一句话结论与阅读价值

**DeePEST-OS 证明了“xTB 采样＋DFT 标注＋Δ-learning 势＋鞍点优化”可在已覆盖的有机反应空间内大幅加速过渡态搜索；最醒目的 0.12 Å 和 0.60 kcal/mol 是成功优化子集相对 DFT 的误差，并非全化学空间或实验精度保证。**

值得学习的核心是如何低成本建立反应势能面数据，以及如何把能量、力和过渡态优化接在一起。它适合关注反应型势、构象筛选与机理计算的研究者。

## 2 文献信息与证据范围

英文原标题：*Reactive machine learning potential for accelerating transition state search in organic synthesis*。Ren、Tang 为共同第一作者，Qilei Liu 为通讯作者。发表于 *Nature Communications* **17, 6253 (2026)**；2026-05-08 在线发表，出版社页面另列 Version of record 为 2026-07-16，已非仅有接受稿。DOI：**10.1038/s41467-026-72945-0**。

本报告读取正式全文、14 页 Supporting Information，并核对公开审稿文件中数据划分、速度比较和实验对照的答复；查看了当前 GitHub README、Zenodo 代码与数据记录。没有下载全部大型数据、重新计算指标或运行模型。

## 3 科学问题与方法定位

要解决的问题是：已知一个基元反应及其合理三维过渡态初猜，能否用接近 xTB 的成本得到接近目标 DFT 的鞍点、IRC 路径与势垒？模型输入为原子种类和坐标，运行时还需 GFN2-xTB 基线计算；输出能量和原子力，再交给 Sella 优化器。它不是仅输入 SMILES 就独立发现未知机理的模型。

覆盖元素为 **C、H、O、N、P、S、F、Cl、Br、I**，数据库体系为 6–50 个总原子。原文工作流依赖反应模板生成初猜；复杂合成路线先由 RetroSynX 提出，再进行候选路径计算，不能据此宣称已完成无先验的反应网络发现。

## 4 方法与技术路线

1. 从教材提取 **255 个 SMARTS 反应模板**，通过计算机辅助分子设计改变取代基，生成约 9 万个初猜。
2. 在 GFN2-xTB 层次优化并做 IRC；剔除验证失败者，保留 **74,837 条路径**。每条选反应物、产物、TS 和正反方向能量斜率最大位置，在这些位置附近做量子热正则模采样，得到约 **750 万个构象**。
3. 随机选择 9,017 条反应，对其 874,176 个构象计算 **ωB97M-V/def2-TZVP** 能量与力。这才是本工作实际用于建模的高层次数据来源 DORTS-9K。
4. 用 MACE 学习高低精度差值：

$$E_{\mathrm{pred}}(\mathbf R)=E_{\mathrm{GFN2-xTB}}(\mathbf R)+\Delta E_\theta(\mathbf R).$$

其中 $\mathbf R$ 为原子坐标，$\Delta E_\theta$ 为网络学习的 DFT 修正；力也以相应差值监督。MACE 的等变表示编码几何对称性、局部高体阶相互作用；xTB 在训练和推理中均保留。补充表 3 列出约 **823 万参数**、2 层相互作用、6 Å 截断及能量/力损失权重均为 10。

5. 将修正势接入 Sella，进行 TS 优化、IRC 和构象筛选。这里的物理先验改善了测试表现，但不是严格保证整个未知势能面拓扑正确的数学约束。

## 5 数据、基准与关键结果

**三个集合必须区分：**DORTS 是 74,837 条 xTB 路径及其采样；DORTS-9K 是 DFT 标注子集；DORTS-1K 是另选的 1,000 条未进入 DORTS-9K 的反应。主文将 DORTS-9K 构象按 8:1:1 随机分为训练、验证、测试，不能把内部构象测试误差等同于新反应泛化能力。

| 结果 | 适用数据／比较对象 | 如何解读 |
|---|---|---|
| 能量 MAE **0.266 kcal/mol**；力 MAE **0.380 kcal/mol/Å** | DORTS-9K 内部测试；纯 MACE 分别为 1.112、0.819 | 支持 Δ-learning 有效；这是构象能量／力误差，不是能垒误差 |
| TS 平均 RMSD **0.12 Å**；反应势能垒 MAE **0.60 kcal/mol** | DORTS-1K 中 DeePEST-OS 成功优化的 **880/1000** 条反应，相对 DFT；纯 MACE 为 0.19 Å、0.93 kcal/mol | 约 88% 优化成功；指标对成功子集有条件，不能忽略其余 120 条 |
| TS 平均 RMSD **0.11 Å**；能垒 MAE **3.80 kcal/mol** | 将原 DORTS 模型直接用于 Transition1x 的 1,073 反应 OOD 测试 | 几何仍接近，但能量泛化明显下降；低 RMSD 不自动代表化学精度 |
| 平均 RMSD **0.050 Å**、能垒 MAE **0.692 kcal/mol** | 在 Transition1x 层次重新训练的 **DeePEST-OS-T1x**，三种方法共同成功的 995 条；React-OT 为 0.077 Å、1.038 kcal/mol | 是另一个重训模型与筛选子集，不能冒充原模型零样本成绩 |
| **1.4 s/TS** 对比 React-OT **1.8 s/TS** | 上述 T1x 对照；审稿答复说明同用 RTX 4060 Laptop，排除了频率计算 | 不是包含 DFT 复核、IRC、热力学校正的总流程时间 |
| TS 搜索单步 **0.17 core·s**，DFT 为 **1568.8 core·s** | 苯与亚硝酸代表案例，约 9,228 倍 | “近万倍”有特定案例与单步计时口径，不是所有体系的端到端加速比 |
| Gibbs 势垒 MAE **1.18 kcal/mol** | Zatosetron 多步合成案例，相对 DFT；含 51 原子步骤 | 有限的大体系外推证据；不等于任意药物合成均可可靠预测 |
| 计算 ΔΔG 与实验 de 的线性相关 **R²=0.76** | **11 个反应物**的 Diels–Alder endo/exo 选择性；DFT 为 0.82 | 实验数值取自既有文献，是小样本回顾性相关检验，未报告独立前瞻实验命中率 |

定位依据：主文 Fig. 4–8、Table 2，Supporting Information Fig. 1–5，公开审稿答复第 4、23 项等。

## 6 化学与物理可靠性

数据生成明确包含 **xTB 层次 IRC 验证**；模型应用也进行了 Sella TS/IRC 计算，并展示与 DFT 路径、反应坐标和二维势能面的一致性。方法给出 TS 最大垂直力阈值 0.0025 eV/Å、IRC 阈值 0.005 eV/Å，失败两次的搜索被剔除。

这些证据强于只报告三维结构 RMSD。但不能将 xTB IRC、模型 IRC 与独立 DFT IRC 混写，更不能把优化收敛等同于连接目标反应物和产物的证明。本次核实范围未见对全部 1,000 个外部样本逐项列出“DFT 单虚频＋目标端点连接”的统一通过率。

模型主任务学习势能面。自由能和实验选择性属于后续案例，不能用前面的 0.60 kcal/mol 替代自由能精度。主文和 SI 未充分交代适用于全部案例的溶剂、温度、标准态及电荷／自旋覆盖范围；不宜外推到显式溶剂动力学、自由基或多自旋金属反应。

## 7 局限与批判性评价

**作者明确承认：**高精度能量／力标注仍昂贵；xTB 推理随体系扩大成为瓶颈；金属体系受基线能力限制；初猜生成依赖模板。DORTS-1K 上每步平均耗时为 0.084 core·s，约为单独 xTB 的 2.53 倍，因此网络并没有消除基线计算成本。

**阅读者判断：**

- **“未见反应”不等于“未见机理”。**公开审稿答复确认 DORTS-9K 包含全部 255 个模板，因此 DORTS-1K 检验的是同一模板库内新结构／取代基组合，而非严格留出反应类别测试。内部构象随机划分也未展示严格反应级隔离。
- **有样本选择效应。**数据先过滤 xTB 路径失败者，性能再对成功优化子集统计，可能低估难反应的实际使用风险。
- **“十元素”覆盖不均匀。**DORTS 中 I、P 的原子占比分别仅约 0.01%、0.1%；元素名单不能替代各元素及反应环境的分层可靠性检验。
- **实验验证强度有限。**11 点线性拟合支持选择性趋势，但 ΔΔG 与产物比例本由温度相关指数关系联系；其 R² 不能当作无校准的产物比例预测精度。
- **适用域判据需重新校准。**文中用 512 维嵌入最近邻距离 0.7 划分适用域，这是该模型的经验阈值，不是可迁移的通用化学距离；正文一处附 Å 不宜据此解释为实际结构距离。

## 8 可复现性与使用门槛

当前 [GitHub 仓库](https://github.com/kaipai-ren/DeePEST-OS) 可公开访问，含模型、外部测试结构、TS/IRC 示例、训练示例和依赖文件；正文仍称 GitHub 为 private repository，与本次访问状态不同。公开版本另归档于 [Zenodo 代码记录](https://doi.org/10.5281/zenodo.19305799)。[DORTS 数据记录](https://doi.org/10.5281/zenodo.17141108) 提供完整数据与读取程序，其中 DORTS-9K.h5 约 4.9 GB。

README 建议 Linux/Conda，至少 16 GB RAM、4 GB 显存的 NVIDIA GPU；也允许 CPU 推理。该建议不是本报告验证的最低配置。论文标注使用 ORCA 6.0.0，初期 xTB 路径借助 Gaussian16 接口；复现完整建库与仅运行已训练势的门槛不同。**本次仅文献阅读，没有安装环境或运行复现。**

## 9 可延伸选题

以下为阅读者建议，不是本文已完成的成果：

1. **严格按模板留出＋主动学习补点：**先评估完全未见模板的成功率和势垒误差，再比较每新增 100 次 DFT 标注的收益，验证低成本迁移是否成立。
2. **以目标端点正确率作为工作流指标：**将生成式初猜接到该势，统计“初猜→鞍点→DFT 单虚频→目标 IRC 连接”完整成功率，并计入所有失败与量化复核成本。
3. **校准选择性而非只拟合相关性：**固定温度、溶剂和标准态，使用构象自由能集合预测 endo/exo 比例，以独立底物测试集检验误差及置信区间。
