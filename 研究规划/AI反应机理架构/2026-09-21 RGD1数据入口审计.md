# RGD1 数据入口审计

当前下载的 `RGD1-version1.0.zip` 只有 `Freaction_features.csv`，共 176,992 条唯一反应 ID 和 30 个聚合特征字段。项目 README 还提到 `RGD1CHNO_AMsmiles.csv`、`RGD1_CHNO.h5` 和 `RGD1_RPs.h5` 等文件，但它们不在这个下载包中。

因此 RGD1 目前只能做反应类别、元素计数和断键/成键数量统计，不能提供：

- 反应物图和具体 atom map；
- 三维 R/TS/P 端点；
- 形式电荷、多重度或微观态；
- 产品无关的具体键编辑标签。

项目中已将 RGD1 标记为“元数据可用、模型输入未就绪”，暂不进入事件或几何训练。审计报告：`mechai/docs/RGD1_DATA_GATE.md`。
