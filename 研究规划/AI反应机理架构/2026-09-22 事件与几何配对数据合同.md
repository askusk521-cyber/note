# 事件—几何配对数据合同 v1

日期：2026-09-22。依据[用户目标校准](<2026-09-22 重要讨论｜科研目标、FlowER定位与主线调整.md>)，本轮只读核对已有 Kingfisher、Transition1x 与 UniTS 资产及报告；没有下载新数据、重跑41条/8条调参或新增量化计算。本文规定能检验什么，原型实现与实验协议分别见[模型假设](<2026-09-22 模型假设V1｜事件与几何共享兼容函数.md>)及相应代码。

**可以给定净转化、反应中心或端点；完全未知产物不是必要条件。现有数据可以直接支撑端点条件几何对照，也有41条事件与TS可按原始ID配对的档案记录；但尚没有通过合同、足以检验跨体系“未知事件/参与溶剂与几何相互约束”假设的匹配训练与留出集。当前耦合原型的运行应标为软件性质检验。**

## 1. 同样本匹配意味着什么

所需的最小记录不是一份图数据加另一份几何数据，而是同一输入条件 `h` 下的事件候选 `e`、相应TS参考 `x` 与来源关系。匹配需保留完整原子清单、单位、电荷/自旋证据、微观态、溶剂成员、组/家族以及标签验证层级。未知值保持未知。

先冻结三个允许的任务口径，分别报告：

| 任务口径 | 可以作为已知条件的信息 | 实际预测变量 | 结论范围 |
|---|---|---|---|
| `endpoint_geometry` | 已声明的R/P坐标或图、原子行对应、必要电子态；允许给定参考来源的反应中心并明示 | 在这些条件下的TS几何 | 端点/中心条件几何；不声称找到了未给定净事件 |
| `intent_event_geometry` | 当前状态与微观态、净重原子转化/中心、允许的物种池及环境；也可给不含完整H归属的产品骨架 | 尚未由条件确定的H去向、参与溶剂模式、基元步骤及TS | 输入合同和已知参考集合内的事件—几何覆盖 |
| `endpoint_microsequence_geometry` | 完整R/P及原子映射 | 净转化之间的基元步骤次序、中间态、返回原态的催化溶剂过程及相应TS | 需要真实多步/路径标签；仅端点净编辑不够 |

不同条件下的分数不能相加后称为同一任务。若某模式给出更完整的P图，它可以是合法的更强条件对照，但不能仍把已确定的变量计作模型预测成功。

## 2. 条件公开后还剩哪些未知量

| 已知条件 | 直接提供或强烈限定了什么 | 仍不能推出什么 |
|---|---|---|
| 反应意图、候选重原子中心 | 待改变的键/位点范围；减少中心发现难度 | 显式H归属、微观步骤、参与水、TS空间排布 |
| 重原子R/P骨架 | 净重原子编辑；有时也限定产物质子化类型 | 未给定的显式H映射、溶剂中质子走向及不同空间通道 |
| **同原子映射、完整显式H的R/P键图与形式电荷** | 端点净键编辑、每个H的最终所有者、净电荷变化；对当前 `EventProposal` 净编辑表示，目标事件基本可直接计算 | 微观转移先后、协同/分步、净变化为零的催化循环、中间态、势垒和TS；对称等价映射仍可能不唯一 |
| R/P完整溶剂H图 | 哪些已标号水在端点净编辑中发生变化；可暴露净H链 | 物理上全部催化/稳定作用的水；端点不变的溶剂参与；链的真实时间顺序 |
| 反应物/产物三维端点 | 构象、相对取向与水网络；显著缩小几何搜索空间 | 具体TS与势垒；独立构象分布、所有竞争路径 |
| 已搜索出的源TS、其水簇提取或参考TS派生中心 | 很强的通道与几何线索；可能使事件排序接近规则解 | 从常规反应物条件发现通道的能力 |
| 水成员掩码 | 哪些原子属于环境水，是已给定物种身份 | 哪些水实际参与事件；必须与 `active_solvent_ids` 标签分开 |

“完整R/P给定后净事件可读”不等于“机理已知”。但若实现的事件变量只是 `ΔBE` 与净H转移清单，就不能把其恢复当作未知机理选择；要么缩小为几何任务，要么给出不同于净编辑的微观步骤变量与相应标签。将完整P图任意遮掉H、再从P坐标恢复H归属，也不构成未知事件任务。

端点与中心可以来自已知反应并作为明确条件。要求独立于参考TS的，是**拟声称由模型发现的变量及其环境采样**，不是禁止一切已知产品信息。

## 3. 已有资产逐项能做到什么

### Kingfisher CH2O：有可连接的事件—TS，输入条件与独立性不足

本轮按 `target_id` 连接已有两个文件，未执行模型拟合或评分：

- [事件记录](<../../../ChatGPT/mechai/data/processed/kingfisher-ch2o-events-v2/events.jsonl>)：41条/19组，SHA256 `ee277408552e4b10149b350902796100ee4ade7ba30e8b836dfdc557ee4da5ae`。
- [源/目标TS几何pair](<../../../ChatGPT/mechai/data/processed/kingfisher-ch2o-pilot-v1/pairs.jsonl>)：50条，SHA256 `4fb779cfb98ec37bc15793f415eb15829bea0d7f30624829e2ee7578d683fd84`。
- **41/41连接成功**，两侧 `source_id`、`group_id`、原子顺序、电荷/多重度和源坐标逐条一致；41个目标TS坐标形状均匹配且有限。逐条ID与本次检查见[连接记录](<../../../ChatGPT/mechai/reports/public/event-geometry-contract-v1/local-join-audit.json>)。这只是字段/来源一致性，未升级原档案映射证据。

现成字段包括当前CH2O/水模板Lewis态、完整原子及水掩码、重原子意图、参考净事件、源TS和DFT TS。参考净事件仍依赖限制域Lewis完成与BO阈值共识，9/50条未知继续保留。源/目标不同理论层次、QM区域和溶剂处理不能简单归为电子结构误差。

输入坐标是已经搜索得到的源TS；41条仅11条/7组有满足给定意图的源端点，端点本身仍由同一次搜索/IRC选择。四水加强规则在原41条源TS任务上首选已达99.12%，11条端点条件前4也已100%。本数据可用于**固定档案的张量连接/证据mask检查及已标明oracle来源的诊断**，不能重新包装成新的独立训练集或再次调参检验耦合收益。

源双向IRC仅3/50明确收敛，DFT均在100步停止；后续两端优化两层均50/50报告收敛。因此标签属于“有限IRC后端点优化的归档连接证据”，不称完整收敛IRC或本项目独立验证。详见[事件结果](<../../../ChatGPT/mechai/docs/EVENT_CORRESPONDENCE_RESULTS.md>)、[输入敏感性](<../../../ChatGPT/mechai/docs/SOURCE_INPUT_SENSITIVITY_RESULTS.md>)、[IRC审计](<../../../ChatGPT/mechai/reports/kingfisher/ch2o-irc-v1/audit.json>)。

### Kingfisher CO2：有几何档案，但不能沿用CH2O事件合同

44条标准water/21组中，23条BO/图歧义，3条无唯一源完整TS；18条图共识端点两端碳都连接3个氧，未匹配原“初始CO2加成单步”意图，其中13条净H变化、5条同图。11条自定义溶剂继续单列。

这些记录可以作为将来**重新定义实际状态与净意图**的候选，但本轮尚无适配的事件标签合同；不能用CH2O价态完成器导出“第二家族”，也不能把不匹配旧意图的记录当成物理负例。[CO2合同证据](<../../../ChatGPT/mechai/docs/RELAY_COVERAGE_AND_CO2_RESULTS.md>)保持原结论。

### Transition1x：端点几何立即可用，耦合事件标签尚缺

本地文件为 `data/raw/public-endpoints-v1/train_rpsb_all.pkl`，SHA256 `36078a96aaf476f762dd4f1cf63a3f598e59b9191e7c1b819c5b007793078f65`。10,073条R/TS/P的行号、元素、坐标形状一致；9,000/1,073是公开拟合/补集划分。可给定R/P坐标，评价已有初猜或新的端点几何模型；**不需要为了合法性刻意禁止P**。

立即可运行的对照是固定这套端点条件和补集、比较普通公开初猜/端点几何生成的RMSD及距离误差。已有 `ts_guess_sbv1` / `ts_guess_NEBCI-xtb` / `ts_guess` 补集RMSD为0.2485 / 0.3526 / 0.4746 Å；这是已完成的诊断，不是本轮新结果。`ts_guess_true`近似参考TS，继续隔离。公开猜测允许作为明确提供的额外条件时，应单独命名为“初猜修正”；不可混入从端点生成的对照。

预处理未提供显式键图、形式电荷或多重度；`charges`实际是原子序数。R/TS/P同序元素是行对应证据，不是经过化学映射验证。缺少受信任的净事件/多步标签、显式水环境和参与水标签；独立家族留出也未核实。几何专用接口可保留未知电子态 `null`，但它因此**不能进入要求明确电荷/单重态的BE事件模块**。

从R/P坐标感知键图是另一个需审计的标注操作，不能自动解决电荷、自旋、对称映射或多步机制；若P图是输入，感知出的净编辑是已知条件。见[字段清单](<../../../ChatGPT/mechai/reports/public/transition1x-v1/field_manifest.json>)、[几何诊断](<../../../ChatGPT/mechai/docs/TRANSITION1X_BASELINE_RESULTS.md>)。旧[端点入口文档](<../../../ChatGPT/mechai/docs/PUBLIC_ENDPOINT_DATA_GATE.md>)中“事件预测必须只输入R”的表述仅适用于其当时单独定义的产品无关任务，不再作为全项目主假设的必要条件。

### UniTS-Lib：发布图/中心条件的几何基线已就绪，不能直接充当未知事件监督

4,391条已有图、参考TS、`chrg`、`mult`、`rct_idx`和图特征；3988/403 Formula-OOS已重建，n2有效预处理为 `data/processed/units-v2/`。原始字段没有按同样本给出的完整R/P端点与已验证事件—溶剂模式标签。`rct_idx`是参考派生条件，不能写成模型自行找到中心；发布图也不因加载成功自动成为独立反应物图。

全局电荷和多重度是实际字段，原记录中存在1,237个双重态；不能只因CHNOS接口支持单重态就把其默认为单重态。`graph_feat`第2列实际是全局 `Q+3`，第9列是全局 `M−1`，不是逐原子形式电荷/自由基标注。官方Formula-OOS按分子式分组，不自动等于反应家族留出；作者完整预训练成员仍缺独立证明。[完整字段审计](<../../../ChatGPT/mechai/reports/E0b/audit.json>)和[官方合同](<../../../ChatGPT/mechai/docs/audits/units_baseline_contract.md>)限定其用途。

可以保留冻结官方主干与既有几何适配设施，但把任何新事件模块接上主干，不会凭空补出匹配监督。原三种子残差与8条诊断不重跑调参。

## 4. 可编码的样本schema

以下是新适配层的逻辑字段合同，不声称已有统一导出器。几何数组可存NPZ并在JSON引用；所有索引指向同一份 `atoms`，使用零基整数。每个可空证据字段采用 `{value, status, source_ref}`；`status`可为 `observed`、`declared`、`derived_under_contract`、`unknown`、`ambiguous`。示例中的 `null`/空数组保持未就绪，不能当成无事件或中性。

`candidate_pool.events[]`每项保存 `event_id`、`delta_be`、`proton_transfers`、`net_active_solvent_ids`、`origin`、`proposal_source_ref`、`representation_valid`与域外原因。完整BE含对角非键电子变化；给coupler的对称非对角原子对编辑只是神经输入，不能替代完整守恒账本。无标签不把 `representation_valid` 设为false。

`labels.references[]`每项保存 `reference_id`、`event_id_or_unknown`、`event_evidence`、`ts_coordinates_ref`、`atom_correspondence`、`electronic_structure_level`、`environment_protocol`、`frequency_evidence`、`irc_evidence`、`endpoint_optimization_evidence`和原始来源。参考列表允许多项；未收录的候选保持未知。现有档案支持的“与此参考不一致”负标签必须命名 `reference_nonmatch`，不能命名 `physically_impossible`。

几何候选是独立对象 `CandidateGeometry`：`coordinates[B,G,N,3]`、`atom_mask[B,N]`、`geometry_valid_mask[B,G]`与 `CandidateGeometrySource`，消耗预算另记账。几何来源区分 `generated_candidate`、`independent_initial_guess` 和默认拒绝的 `reference_ts_oracle`。耦合输入 `EventGeometryCondition`包含 `event_features[B,E,F]`、`pair_edits[B,E,N,N]`、`event_valid_mask[B,E]`和 `ConditionSource`。兼容分数 `[B,E,G]`可以在采样中读取当前候选坐标；参考TS只在损失/评价侧读取。`q(e|h,x)`是候选间相容分布，不是Boltzmann权重、通量或产率。

## 5. 启动门槛与允许的降级方式

| gate | 必须满足 | 不满足时允许做什么 |
|---|---|---|
| G0：可追溯与固定预算 | 版本/hash、全部源ID、条件白名单、标签侧隔离、总几何候选与筛选预算预先固定 | 做纯合成软件检验；不能报真实数据收益 |
| G1：几何一致性 | 明确单位、同原子清单/行对应、有限坐标、R/P/TS角色；镜像和化学等价映射口径公开 | 缺图/Q/M可做明确的几何专用任务；禁止补零进入BE适配 |
| G2：事件与三维同样本 | 完整明确状态/电荷/自旋域、受信任的事件与参考TS链接、条件没有已经确定全部待评事件变量；参与水含义明确 | 仅做事件已给定的几何控制或档案连接检查；不宣称未知事件耦合 |
| G3：与假设匹配的评价 | 训练/选择/最终留出按来源及所声称家族隔离；多个环境/体系有足够独立组；包含候选覆盖失败与未知；三种子/不确定性及有用效应预先固定 | 小样本描述性诊断；不能以新增模型参数补足独立样本 |
| G4：通道发现或科学机理结论 | 同一声明输入下可验证的多参考事件—TS/端点证据；要称完整通道覆盖须另有覆盖证据；后期独立物理验证 | 只报已知参考保留率，不称找全通道、降低真实遗漏率或解释产率 |

G1通过不意味着G2通过。已有单个参考可以支持“已知参考保留”的受限评价；它不能把其余候选标为物理负例，也不能建立真正多通道召回。给定R/P的几何任务不必通过图事件gate，模型原型的接口/梯度检验也不必等FlowER全量审计。

本轮具体结论：Transition1x具备G1级端点几何入口，现存补集仍不具备所声称的家族独立性；Kingfisher具备部分G2字段连接，但目标主假设的输入与G3证据不足；UniTS具备已声明图/中心条件的几何基线，但没有该假设所需的完整事件—环境标签。**没有数据集通过本轮耦合主假设正式训练/效应评价的全部gate。**

## 6. 最少还需补哪类匹配证据

需要同一固定反应条件下、未按目标TS选取的当前微观态/环境（或明示为给定的完整端点），以及对应的事件/微观步骤与三维参考。若任务给完整R/P，必须另有未被净编辑确定的多步或溶剂过程标签；若仅给净重原子意图，需要保留显式H/参与水的候选与有证据的参考集合。还需多反应家族的来源关联、独立留出及明确电荷/自旋与映射证据。

这些缺口不能通过把FlowER边贴到Transition1x行上补齐，也不能通过从参考TS挑参与水后隐藏来源补齐。现有资产内重建更多派生标签必须另行说明假设与未知比例；必要字段不存在时需要新的匹配来源/标注，起步不新增DFT的约束仍有效。

下一步可并行完成coupler原型、强对照和端点几何适配协议，先证明零耦合退化、旋转/平移/原子置换、证据mask和有限预算正确。真实耦合训练启动以前，先提供通过G2/G3的样本清单与冻结条件；没有这份清单时将原型结果明确标为软件证据，不为安排GPU实跑放松合同。
