# Kingfisher甲醛—水数据：配对审计与下一步模型合同

更新：2026-09-21。来源：[Kingfisher supporting data v1.1](https://doi.org/10.5281/zenodo.15297813)，元数据许可CC-BY-4.0。下载了28.5 MB的甲醛—水数据库成员，通过HTTP Range、ZIP成员CRC和SHA256校验；没有下载整个3.7 GB归档，**没有核验全归档MD5**。没有执行归档的量化启动脚本。

完整审计：`reports/kingfisher/ch2o-v1/`；最新配对审计：`reports/kingfisher/ch2o-pairs-v2/`。v1配对结果保留，v2加强了频率属性归属和非空端点校验，计数未改变。

| 层级 | 数量 | 解释 |

51组配对为10–28原子，对应CH2O＋2–8个水的组成。它们来自25个Kingfisher随机种子值，有10个源reaction ID；**不是51个独立化学反应，也不能直接把10个ID称作10条不同机理通道。** 51组均有源端点ID和spline记录。数据中已有DFT结果可供起步，不需要用户另做DFT来建立这批参考标签。

51组中有一组的后续频率属性出现两个负值。没有先假定第二个是噪声，也没有在频率单位未完整确认前随意设阈值；各次属性及计算ID都保留在`pairs.jsonl`。50是下一轮审计候选池，**还不是已经完成去重、原子映射和质量认证的训练集**。

## 输入到底是什么

可追溯关系为：

```text
源反应物＋Kingfisher设置/随机种子
    → 已有GFN2/SFAM搜索与QM区域提取
    → 微溶剂化TS初猜
    → 已有DFT优化TS、频率、端点与spline
```

可直接监督的任务是“已产生的低层次TS初猜 → 高层次参考TS”。不能把TS初猜当作尚未发生反应的独立溶剂构型，也不能声称这个配对已经支持从反应物发现所有通道。输入几何由半经验/QM-MM流程产生，但后续模型训练只读取归档，不新运行半经验或DFT计算。

DFT元数据、源频率符号、端点链接和spline属于已发表计算的源证据；本项目尚未独立验证IRC。配对审计只读取BSON，未启动MongoDB或SCINE计算服务。

## 还需补齐的数据合同

1. **单位约定已核对，导出尚未实现**：SCINE读写源码、作者归档分析脚本均采用内部Bohr。将数据库中原始甲醛的四个原子按0.529177210903 Å/Bohr转换后，与归档XYZ的对应坐标最大误差为5.34×10⁻¹⁰ Å；证据见`reports/kingfisher/coordinate-evidence.json`。后续导出器必须显式记录转换，原数据库保持原样；该核对不证明后续优化的同元素原子映射。
2. **原子对应**：51对元素顺序、电荷和自旋相符，且有明确输入/输出关系；这仍不能单凭元素序列证明同元素氢/水未发生置换。需结合源优化程序的原子顺序合同、端点/图映射和几何核查。
3. **重复与划分**：同Kingfisher种子、共享计算祖先及同一物理结构必须同组。先去重再固定划分；不随机打散51条。甲醛内留种子只检验溶剂采样迁移，不证明跨反应家族泛化。
4. **标签覆盖**：列出每对参考反应中心、氢键/接力拓扑能否可靠读取。没有记录的通道不当负样本，源成功TS集合不当作通道全集。

## 下一步可证伪问题与最小架构

暂定问题：**对于同一水参与基元反应，半经验初猜到DFT参考之间是否存在可由局部溶剂环境预测的系统几何偏差？在未见过的溶剂采样种子上，AI是否优于保留原初猜？** 先检验偏差是否足够大、是否跨种子可重复，再投入生成模型。它是目标氨酰化问题的受控方法诊断，不能代替最终生命起源体系。

数据合同通过后，先固定两项对照：原初猜恒等映射，以及只在训练组拟合的简单等变距离特征回归。最小AI模型再使用小型等变残差网络：

```text
源初猜元素、坐标、电荷/自旋、可从输入得到的局部环境
    → 距离/氢键邻域编码
    → 等变位移 ΔX（总质心位移为零）
    → 校正候选 X + ΔX
```

不从目标DFT TS生成输入图或标出“正确的水”；目标只用于训练损失和留出评价。先保留原子数、元素和总电荷，学习坐标修正；这是基本守恒，不等于已经实现FlowER的电子记账约束。初期不叠加flow、通道分类头与能量网络。

评价包括固定映射/化学等价映射几何、反应中心与水的局部距离误差、碰撞和手性，并报告每个种子及失败记录。50条量级不支持从零训练大型生成器，也不足以证明广泛机理发现。若可学习偏差不稳定，或原初猜已足够接近参考，应停止这条修正任务；再评估其他反应家族的环境条件/通道覆盖问题，而不是靠扩模型强行获得改善。

最终科学目标仍需独立DFT验证新候选、竞争路径与选择性；本阶段的已有DFT标签只是训练/诊断参考。
