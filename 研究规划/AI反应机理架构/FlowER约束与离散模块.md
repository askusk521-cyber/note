# FlowER 的可迁移约束与我们的离散机理模块

核查日期：2026-09-21。本文区分 **[论文]**、**[代码]** 和 **[设计建议]**。仅阅读既有正文、SI 与官方源码；未运行模型或化学计算。

**建议采用 FlowER 的固定原子记账、显式氢和守恒生成思想，但不直接复制整套稠密 BE 流模型。** 对硫酯—核苷—水任务，先把“给定微观态下，哪些原子参与哪一个候选事件、哪些水/酸碱参与质子交换”定义为可核验的离散模块，再接三维候选和量化验证。水数与微观态选择应在单次守恒变换之外处理；多步路径应由搜索器组织，不能把模型的流时间当作化学反应时间。

## 2. FlowER 实际学的对象

### 2.1 BE 不是电子密度，也不包含核坐标

**[论文＋代码]** 对固定的、原子映射一致的显式原子集合建立 `N×N` BE 矩阵：

- `B[i,j] = bond_order(i,j)`，`i != j`。单键在两个对称位置各记 1，整个矩阵合计记 2 个价电子。
- `B[i,i]` 是该原子的**非键价电子数**，并非孤对电子“对数”。例如水中氧的对角项为 4，不是 2。
- 在全部氢均为独立节点的前提下，`q_i = valence_electrons(Z_i) - B[i,i] - sum(j!=i) B[i,j]`。于是 `sum(B) = sum_i valence_electrons(Z_i) - Q`，总电荷 `Q` 与价电子总数的守恒对应。
- 芳香体系先 Kekulé 化为整数键级。它是 Lewis 图的记账表示，不是实际电子密度、轨道、自旋波函数或三维反应路径。

代码定位：现行 `utils/data_utils.py` 的 `count_lone_pairs`、`get_BE_matrix`、`get_formal_charge`。论文定位：Methods “BE matrix design choices and featurization”；SI S3.3。

**可迁移部分**：全体反应物、产物、酸碱伙伴和参与水的原子及价电子在一次变换中守恒。**缺失部分**：仅元素与 BE 无法表达构象、氢键几何、核糖立体化学或完整环境稳定化；合法 Lewis 图也不一定是可存在的驻点。

### 2.2 网络层、条件与输出

| 项目 | 已核实的实现 | 对我们的含义 |
|---|---|---|
| 原子输入 | 元素 one-hot 的可学习嵌入；源码用 `nn.Embedding`。没有单独学习原子映射编号 | 映射编号只是记账；不应把水编号或 atom-map 当化学特征 |
| 原子对输入 | 当前连续 BE 数值经 RBF 展开，与正弦伪时间嵌入拼接，作相对位置特征进入多头注意力 | 这里的“位置”来自 BE，不是三维空间位置 |
| 编码器 | 图 Transformer：LayerNorm、多头相对注意力、残差、前馈网络 | 可用相似骨架编码图，但需新增稳定的状态/环境条件 |
| 基础版本设置 | tag 1.0.0：12 层、32 heads、128 维、前馈宽度 2048；sigma 0.15，RBF low/high/gap 为 0/8/0.1 | 这是查到的代码设定，不是我们必须照搬的设计原则 |
| 非对角输出 | 两组原子表示点积，再加 BE/时间相关残差，形成键变化预测 | 输出连续变化量，不直接为各键采样离散类别 |
| 对角输出 | 另设 query/key/value 聚合和投影，给出各原子非键电子变化 | 键与非键电子变化必须联合校验 |
| 条件接口 | 编码器接收元素/其嵌入、有效长度、当前 BE 与 t；无独立产品端、反应中心、pH、温度、3D 条件输入 | CFM 中的“conditional”不能误读为已有任意实验条件控制 |

证据：SI Fig. S1；[tag 1.0.0 encoder](https://github.com/FongMunHong/FlowER/blob/152c02cbfeccacd659c3bf60326d088f79ec0f3f/model/attn_encoder.py)、[settings](https://github.com/FongMunHong/FlowER/blob/152c02cbfeccacd659c3bf60326d088f79ec0f3f/settings.py)。注意：基础模型训练时先把元素 token 转为嵌入再传入 `forward`；新版本在 `forward` 内转换，输入化学信息没有因此改变。

**[代码]** 现行搜索脚本会 `AddHs` 后建立映射，但标准化和清理使用 `isomericSmiles=False`，且模型没有单独立体特征通道。因此不能直接用其现行输入清理逻辑处理需要保持核糖立体化学、比较 2′/3′ 位点的任务。

### 2.3 连续守恒、离散取整和价态不是同一层约束

**[论文]** 加入的高斯噪声先去均值、再对称化；输出向量场也去均值、对称化，满足 `v = v.T` 和 `sum(v)=0`。只要初始矩阵合法，连续 ODE 保持价电子总数及矩阵对称；固定原子集合保持元素和显式氢记账。

**[SI S5]** ODE 终点仍是连续数，需 sum-safe rounding 转成整数。但 S5.3 明确说明：**保和取整不能保证离散后的矩阵对称**，负电子数和错误价态也仍会出现。因此“守恒架构”不能写成“所有生成分子都合法”。

**[SI S5.2＋现行源码]** 可选 validity fix 尝试恢复每个原子的原先周围电子数。源码用 `row_sum + column_sum - diagonal` 计算，实际上是把成键电子都计入的局部壳层占据数，而不是元素固定的外层电子数。它对遵循八隅体的常见 HCNOF 结构有效，但不能作为所有反应态的普遍定律：缺电子碳、自由基、超价硫等并不都要求每原子始终保持同一个数。对我们的含硫反应，应列出允许的硫价态/电荷状态，而非盲目拷贝修复函数。

### 2.4 显式氢、酸碱与数据标签

**[论文/SI S3]** 初始 USPTO 总反应经专家 SMARTS 模板补中间步骤，并只保留通向已报道产物的分支；原始合并训练集为 250,782 个总反应、1,445,189 个步骤。修订版 S11 为 257,159 个总反应、1,933,781 个训练步骤，需锁定版本。

模板用 88 对酸碱的 pKa 阈值，从物种池选质子供体或受体，显式补入其共轭伙伴以守恒氢。**这不是全局酸碱平衡，也不是微观态布居模型。** 作者承认强酸/强碱可能不合理共存，加料阶段与后处理物种也混在一起。

S11 修正了无溶剂参与的可疑分子内质子转移，以及跳过四面体中间体的压缩标签。此处的教训是需要物理验证与标签版本控制；**不能反过来把“所有酰基转移都必须具有稳定四面体中间体”硬编码为普遍规律**，应由具体体系的驻点和路径连接决定分步还是协同。

### 2.5 损失与多步生成

**[论文]** CFM 学习线性插值附近的向量场，解析监督为端点差 `u = B1 - B0`，损失是 `E ||v_theta(t,B_t,Z)-u||²`。t 是 `[0,1]` 上的生成伪时间；它既不是速率，也不是化学反应坐标。

**[代码细节]** 两个官方 tag 的 `train.py` 都对源端另加噪声，以 `B1 - noisy(B0)` 为监督；`B_t` 由 clean `B0,B1` 的插值再加噪声得到。实现先遮掉 padding，再对平方误差求和、除以 batch 样本数，不是除以有效矩阵元素数。复现必须明确这一细节；不能只照简化公式推断训练代码。此处没有 TS、势垒、三维几何或实验选择性损失。

**[论文/SI S7.1]** 单次 ODE 预测一个下一步状态，多步通过外部扩展/beam search 实现。重复样本频率用于候选排序，不是 Boltzmann 权重或反应通量。多步不是一次 ODE 轨迹穿过多个真实中间体。

## 3. 建议的离散模块：微观态固定、事件与参与者联合提案

以下均为 **[设计建议]**，不是 FlowER 已有功能，也不是已证实的新颖性。

### 3.1 模块边界与接口

建议的逻辑顺序：

`微观态/局部环境集合 → 状态图编码 → 事件与参与者提案 → 守恒离散解码 → 三维候选模块 → TS/IRC等物理验证 → 更新搜索图`

单个输入状态 `S_m` 至少保存：显式原子和映射、元素/形式电荷/键图/必要立体标签、总电荷与自旋设定、酸碱物种完整清单、已知酰基中心及可反应位点、当前局部水集合。若已有构象，可补充距离/氢键候选图；若未确定构象，不能据单个氢键图硬裁掉所有需水重排的路径。

输出不是“机理已确定”，而是一组可供验证的候选：

`(微观态ID, 反应事件, 改键/电荷结果, 显式H交换关系, 参与水/酸碱集合, 模型提案分数, 待验证标记)`。

模型提案分数只衡量候选排序置信度；微观态平衡权重、活化自由能、速率另存，不合并成一个未校准的“概率”。

### 3.2 三个可学习头，加一个确定性约束层

1. **事件头**：在已知酰基中心下预测亲核位点与候选改键事件，例如核苷 2′/3′-O 进攻、水竞争水解、羰基加成、离去基团消除、纯质子交换。自由氨基的角色应包含“不参与/作酸碱/可能参与其他化学”分支，不能先验认定它一定构成接力。事件类别是组织候选的标签，不预判该事件一定对应单个 TS。
2. **参与者与 H 交换头**：对水和酸碱伙伴使用集合选择/指针解码，给出供体—H—受体交换图或有序接力候选。一次水链接力可能涉及多个不同 H 同时交换，不能简化成“同一个 H 沿整条链移动”。等价水置换应等价计分，不以 W1/W2 编号当标签；存在三维环境时用其环境区分角色。
3. **环境作用头**：区分“直接参与 H/键变化”“主要稳定反应物”“主要稳定 TS/中间体”“当前无证据重要”。最后几类需要独立的能量/路径证据，不能把 TS 正常模位移小就自动标作无关。用于环境候选排序，不能自称直接给出了自由能。
4. **守恒解码层**：联合构造离散 `B'` 与形式电荷，硬性检查原子映射、总电荷/价电子、非负整数、矩阵对称和允许价态；显式 H 不消失，纯酸碱步包含共轭伙伴。拒绝不满足条件的提案，并记录拒绝原因。

初版可先用“结构化分类/指针提案＋约束图编辑”，不必为模仿 FlowER 而预测所有原子对的稠密连续场。它仍可泛化选择参与者与组合，是否优于规则枚举则由外推与通道覆盖实验判断。若后续证据表明稠密 BE 流能覆盖结构化事件头遗漏的化学，再作为可比较分支引入。

### 3.3 若保留 BE 流，如何正确迁移约束

固定一次预测的原子集合，只对可变位置作上三角参数化；镜像生成下三角，避免独立取整两侧。令 `u` 为对角和上三角独立变量，权重 `w` 在对角为 1、非对角为 2，则价电子约束为 `w·u = E_val`。对候选速度可用：

`v_cons = v - w * (w·v)/(w·w)`

这里仅在允许改动的变量集合上投影；固定项不参与重新分配，padding 永远不参与。解码需要在非负整数、电子总数、允许键级及形式电荷/价态约束下联合选择最近或高分结构。不能对 full matrix 保和取整后再随意修复对称，因为第二次修复可能再次改变电子总数。

若给定事件已经导出了严格守恒的离散编辑，直接使用该编辑即可，无需重复投影。局部可变掩码必须覆盖整条被提案的 H 交换路径；若把接力水或离去基团冻结在掩码之外，守恒层无法补救候选空间缺失。

## 4. 三项不能照搬的结构问题

### 不同水数

FlowER 的一次 ODE 必须固定 N；不同 n 个水属于不同原子集合和不同维度，不可直接对不同大小 BE 做线性插值，也不可让 PAD 节点吸收/释放电子。

初版可在外层构造若干 n 的局部环境，每个环境内部守恒预测；或先设固定显式水池，让模型选择参与子集。后者的“未参与水”仍是物理水，不是 padding。水数变化本身还改变化学计量和标准态，比较不同 n 的团簇势垒时必须由后端采用一致的热力学约定；网络样本频率无法完成这一转换。

### 不同质子化态

pH 不应直接令有限原子体系凭空增减 H。可在外层枚举/生成酸碱微观态，给出依据 pKa/自由能模型的布居或不确定度；每个微观态内部包含完整质子伙伴并守恒计算。若确需交换质子库，要显式定义储库化学势及交换事件，不能让 BE 投影承担它未包含的开放系统物理。

不应强制所有强酸碱立即瞬时中和，也不应默认它们可以任意共存；应依据明确的实验阶段、微观态与平衡假设形成输入，并标注相关不确定性。条件 token 可以辅助学习，但不能代替这层物种记账。

### 多步与协同路径

每一步先生成候选图变化，再由三维验证判断是单步、分步或无对应路径。允许“加成＋H 交换”“消除＋H 交换”耦合提案，也保留分步替代，不把全部质子变化都拆成稳定离子中间体。

搜索器按带电荷、立体信息及物种计量的规范图合并相同状态，记录可逆酸碱边和已探索边，避免水交换或反复质子化产生无限循环。无变化预测不是“实验反应结束”的证据。候选路径的真正动力学筛选须等到可靠的通道能量与微观态权重齐备。

## 5. 数据与损失应围绕真实判据设计

**训练数据分层。** 模板标签可做预训练/候选初始化；独立量化确认的 TS/IRC 通道标作另一层；只有总产物实验的记录不能充当中间机理真值。保留候选来源、失败原因和未知状态。“一次优化失败”不等于“不存在反应”。不按已知产物删除所有竞争支路再把数据称作完整机理空间。

**离散初版的损失。** 可用事件类别损失、参与者/交换图的结构化似然、约束解码后的候选排序损失；重要性/物理有效性头只在有独立标签时监督。对于多个已知可行机理，按允许目标集合计算似然或采用多标签目标；不能把所有未观察路径都当负例。对等价水和等价 H 标签作匹配或等价化处理，避免学习任意映射编号。

**可选流损失。** 若采用 BE-CFM，单独报告它和离散初版的收益；原实现的全矩阵逐样本平方和会随原子数/大量不变项变化。对我们的可变水数任务，应显式定义按样本/活性区的归一化与活性位置采样；若任意重加权/掩码，需承认训练目标已改变，不能继续声称原 CFM 公式原样成立。

**必须检验的泛化。** 按底物/保护基类别、核苷改造、微观态或环境划分测试；同一反应的水置换和构象不得跨训练测试泄漏。评价分开给：严格化学合法率、去重后的正确通道召回、TS/IRC 确认连接率、重要竞争机制遗漏、外推与置信度校准。以结构化枚举/构象采样和 Kingfisher 级流程为对照，不能只比端点 RMSD 或模板 top-k。

## 6. 最值得带回架构讨论的结论

FlowER 最值得迁移的是**把化学计量作为生成对象的一部分**；最不应照搬的是把局部模板酸碱规则、逐元素保和取整和产物导向的标签剪枝当作已解决的物理问题。对当前选题，一个边界清晰的模型应学习“给定具体微观态与局部环境时的竞争事件/参与者提案”，让三维模块及量化验证负责把离散假设变成真实路径。这个设计是否构成方法创新，仍取决于它能否在未见体系上改善重要通道覆盖与机理判断，而不只是更快地重现规则枚举。
