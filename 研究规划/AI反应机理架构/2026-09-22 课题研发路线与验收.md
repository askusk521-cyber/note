# 研发路线：按输入与证据逐步推进

日期：2026-09-22。本文件是课题审阅后的研发顺序，**未执行的事项都是计划**。科学目标见[课题审阅](<2026-09-22 课题审阅｜目标与研究判断.md>)，实际结果见[STATUS](<2026-09-22 mechai当前进展.md>)。原E0/E1/E2/E3实验编号及冻结配置继续保留；下述R0–R4仅用于组织后续工作，不重命名历史run。

## 1. 阶段、交付物与停止条件

| 阶段 | 工作与交付物 | 进入下一阶段的条件 | 不满足时的处理 |
|---|---|---|---|
| R0：数据与任务合同 | FlowER组内状态网络、全量身份/分组清单、元素/电荷/自由基/BE与特殊类政策；另列目标水相数据缺口 | 输入独立于标签；留出可审计；范围内表示能往返；有足够组支持所声称的比较 | 报告无法检验的命题；保留范围外数据与原因，避免为训练强行删改 |
| R1：最小图事件基线 | 在固定任务上比较规则/局部频率与一个最小学习模型；报告候选覆盖、合法性、停止事件和分组误差 | 相同预算下存在有实际意义、跨种子稳定的增益；测试前固定最小有用效应和不确定性口径 | 若频率/规则已足够，结束该方法支线；不以更大网络代替证据 |
| R2：事件与三维的连接 | 找到同一原子清单、状态、事件和几何可配对的数据；比较有/无显式事件条件 | 可靠事件/几何配对和独立留出成立；收益超过参考选优或TS条件捷径 | 只保留端点几何诊断，停止声称已连接产品无关事件提案 |
| R3：目标体系迁移 | 完整核苷、供体微观态、构象/水环境及水解分支的候选协议；未见结构扰动留出 | 科学比较与输入来源固定；拟议方法适配含S、电荷、手性等域；具备后期物理验证方案 | 若公开标签不能支撑迁移，明确缺口；不把图预测指标包装成目标体系结果 |
| R4：独立物理验证与解释 | 固定模型/选样后做独立TS优化、频率、IRC/端点、竞争势垒；与传统搜索比较 | 相对结论对必要的微观态/构象/溶剂处理稳健，并解释/预测结构扰动 | 保留失败及替代解释；自由能/动力学不足时限制为局部路径结论 |

R0已有格式和抽样基础，尚未完成。R1的USPTO净编辑控制已完成，但不是FlowER下一步基线。R2已有几何设施，没有通过完整连接条件。R3/R4尚未启动目标实验。R4属于项目后期；本轮及起步阶段不新增DFT/xTB。

## 2. 下一项有界工作：FlowER真实状态入口

### 2.1 恢复状态网络，而非按文件顺序串路径

- 保留`(dataset, split, numeric_id)`来源键；数字相同不跨split自动合组。
- 用保留显式H、同位素、立体、电荷和自由基状态的规范图建立有向边“当前状态→下一状态”。分别统计分支、环、断连、重复边、多起点、恒等边及缺失信息。
- 图状态身份与原子映射分别处理：身份比较不使用map数值，边上保留映射追踪；审计对称等价原子引起的编辑多解。
- 恒等步骤是待核对的标签，不先断言全部代表停止。停止语义须由数据构造/官方实现与网络结构共同确认；多重度缺失继续保留未知。
- 两版先各自建图。只有建立反应身份对应后才比较模板修订差异，不按ID或各自随机样本做成对质量结论。

交付：小型计数报告、异常样例、完整索引位置与哈希、输入/标签字段白名单；不需要GPU。

### 2.2 全量身份审计与独立留出

- 全量检查起始与中间状态的重复、相同输入多标签、反应来源联系及特殊类重叠。模型训练不按step随机拆分。
- 按核实的来源联系和**完整输入状态**共享建立传递分组；同时检查与任务相关的主要底物/骨架联系，报告其额外限制。不要因为共享一个水分子或常见试剂就合并全部反应。
- 分别报告官方split和新的去重留出；规则/频率统计、标准化和模型选择只读取训练/验证组。
- 新旧版本不互作“独立测试”：两者可能共享来源。若合用，先按核实的身份联合分组；否则锁定一个版本为主实验，另一版只作匹配修订诊断。
- PC/PM/RS/RC单列审计，事先固定纳入、隔离及评价政策；抽样没有覆盖其化学合同，不能假定已通过。

交付：带哈希的组清单/split、跨组重复计数、每层留出能支持的泛化声明。若大量记录连成大组或新类型不足，应缩小声明，不拆开关联组来凑样本。

### 2.3 化学表示与模型范围

首先核查域覆盖。现有抽样中97.60%/98.11%的完整输入含CHNOS外元素；这是**完整物种池**的计数，不等于这些元素都在反应中心，也不意味着可以删除它们。需区分反应中心、反应物和旁观物种，同时保留完整原子/电荷账本。

明确芳香/Kekulé、整数BE、形式电荷、非键电子、自由基与缺失多重度的处理。对支持域验证图→BE→图的往返和守恒；不支持域记录原因。不得将“无RDKit自由基”升级为已知单重态，也不静默把未知电荷设为零。

范围扩展是否必要由覆盖审计决定。为图任务新增适配层，不等于授权将现有CHNOS配对电子模块改成所有元素/自旋通用模型。

## 3. R1怎样构成有意义的AI实验

固定单步任务：模型只接收当前状态；标签是已报道/模板给出的下一状态集合。给定或不给定反应意图应分开运行和命名；不能把来源类别、目标产物或后续中间体隐含地当作输入。

| 比较项 | 最低要求 |
|---|---|
| 控制 | uniform、训练集局部频率、范围适配的守恒规则；若比较官方FlowER，先核对其预训练成员，不将重新划出的已见数据称为独立测试 |
| 最小改动 | 仅改变一个提案/排序组件；当前图数据没有三维环境，不在这个任务上声称检验环境几何收益 |
| 预算 | 报告1/4/8等固定输出预算及生成/筛选总成本；扩大候选池与改善排序分开归因 |
| 分母 | 所有范围内输入及失败均计入；提案未覆盖的参考不能从排序分母删除；停止事件单独报告 |
| 指标 | 组等权已知下一步覆盖、合法性/守恒、完整编辑恢复、停止预测；有可靠标签时再评估从起点独立展开的序列，不用逐步教师输入代替 |
| 稳定性 | 学习模型原则上3种子；独立组与种子分别报告，预先固定主指标及有用效应门槛 |
| 解释边界 | 未收录通道不是物理负例；模板准确率不是独立机理准确率，也不是通量或产率 |

统计目标可以是“恢复这组已知标签”。未知竞争路径不因此标为物理不可行；对同输入多标签要保留集合，避免把一个已知下一步当成另一个样本的错误化学。

## 4. R2与水相研究之间的必要连接

先回答：同一输入状态能否同时获得可靠事件标签与三维结构？缺少这一对应时，FlowER和Transition1x只能是两个各自成立的接口任务。

有对应后，再固定以下比较：强规则事件＋同一几何生成器、学习事件＋同一生成器、无显式事件条件生成，以及单列的事件oracle上界。每个输入的**总几何候选预算相同**，不能给每个事件额外一份预算。报告原子映射和化学允许的等价映射、碰撞、手性、已有参考事件内几何与未匹配/失败比例。

水相命题还要求：反应物构象和水环境不由目标TS/IRC选择；电荷/自旋和微观态明确；训练与测试覆盖环境变化；候选集不只保留通向已知产物的分支。公开数据缺乏完整物理标签时，可以保留未知候选作后期验证对象，但不能将其伪装为已验证训练正/负例。

后期比较不同水数的簇、不同质子化态或分子数时，需采用可比较的参照、标准态和物种/构象权重，不能直接按不同组成的最低电子能排名。若静态簇排序不能稳定解释趋势，再评估自由能采样的必要性；不在当前阶段同时引入势能学习与反应动力学。

## 5. 建议的下一轮工作顺序

以下是有时间边界的工作建议，不表示已经启动，也不重置原先“一周判断可行性”的要求。

| 顺序 | 建议投入 | 交付与决策 |
|---|---|---|
| 1 | 1–2个工作日 | R0状态网络、完整输入身份与化学域报告；若全量处理未完成，标明覆盖范围并暂不训练 |
| 2 | 约1个工作日 | 冻结输入/标签/分组/预算与强基线协议；同时完成一页“公开数据距目标水相任务仍缺什么” |
| 3 | 1–2个工作日，仅在R0通过后 | 一个最小图事件对照，或明确记录该数据不足以检验所提命题 |
| 4 | 本轮末复盘 | 分别给出工程可行性、AI增益、水相可迁移性判断；决定继续、缩小命题或结束此支线 |

此轮不以同时接入更多数据库或扩大网络为目标。Transition1x保留现有端点初猜对照，USPTO保留频率控制，Kingfisher保留失败/捷径诊断；只有明确缺失字段和可检验问题后，才选择新的公开资产。
